# Support

OpenCode Lab is experimental pre-1.0 software maintained on a best-effort basis.

- Use GitHub Discussions for usage questions and design discussion when enabled.
- Use the issue templates for reproducible bugs and scoped feature requests.
- Use private vulnerability reporting for security issues; never post secrets.

Support covers the latest tagged `0.x` release on supported macOS and Docker
Desktop configurations. Private packs, local policy changes, paid model
accounts, third-party outages, and downstream forks remain the operator's
responsibility. There is no uptime, response-time, compatibility, or data
recovery guarantee.
