# OpenCode Lab v0.1.0-beta.1

The first beta provides a project-neutral Docker-isolated OpenCode launcher,
scoped capability and network boundaries, clean project lifecycle commands,
durable managed runs, evidence-linked `/runs` operations, versioned packs,
artifact and notification indexes, and staged update/rollback support.

This remains a beta for supported macOS/Apple silicon hosts. Generated changes
still require operator judgment, optional profiles increase the attack surface,
and strict microVM execution is not included in this release.

See `CHANGELOG.md`, `migrations/manifest.json`, `SECURITY.md`, and
`docs/compatibility.md` before installing or upgrading.
